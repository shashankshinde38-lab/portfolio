SUPABASE_ANON_KEY=sb_publishable_bcRcnJIIhd0RWwqiPRno8w_dvfP_i2x
SUPABASE_SERVICE_ROLE_KEY=

# Admin Panel Security
ADMIN_PIN=
ADMIN_SESSION_SECRET=
--------------------------------------------------------------------------------

EXPLANATION OF VARIABLES:
1. NEXT_PUBLIC_SUPABASE_URL
   The API gateway URL for your Supabase project (hewlazutzsczzhvtjmax).

2. NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY / SUPABASE_ANON_KEY
   The public publishable key for browser and public access to Supabase.

3. SUPABASE_SERVICE_ROLE_KEY
   The secret service role key for privileged backend API and database operations.
   (Keep this secret! Do NOT commit this key to GitHub).

4. ADMIN_PIN
   The 6-digit access code (752002) required to unlock the Admin Dashboard at /admin/login.

5. ADMIN_SESSION_SECRET
   A secure salt string used by the server to create session cookies upon successful PIN verification.
